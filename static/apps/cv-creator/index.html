Export as PDF

Your browser's print dialog will open. To get a clean PDF:

  1. Set Destination to Save as PDF.
  2. Set Margins to Default and turn Headers and footers off.
  3. Turn Background graphics on (needed for the Modern sidebar).

The PDF keeps real, selectable text and working links.
