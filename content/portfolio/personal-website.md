The site you're looking at. It's built with [Hugo](https://gohugo.io) and deployed to GitHub Pages
on every push with GitHub Actions.

## Highlights

- **Blog from Markdown**: new posts are just `.md` files.
- **Music player** with a playlist, media-key support and download links.
- **Light and dark themes** that follow your system setting.
- **No tracking, no heavy frameworks**: just HTML, CSS and a small JavaScript file.
